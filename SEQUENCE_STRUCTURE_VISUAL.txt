[▓▓▓] = Performance/Control tokens (WITH CONTROL_OFFSET)

KEY INSIGHTS
============

1. SYMMETRIC STRUCTURE:
   ┌─────────────┬──────────────────┬─────────────┐
   │  33 prefix  │   Alternating    │ 33 trailing │
   │  (context)  │   (generation)   │  (no future)│
   └─────────────┴──────────────────┴─────────────┘

2. CONTEXT PROVISION:
   - First 33 controls provide initial context
   - Remaining controls (34+) revealed gradually
   - Last 33 events generated without future information

3. TRAINING-INFERENCE CONSISTENCY:
   Training: Model learns to generate scores given performance controls
   Inference: Model generates performance given same control format
   → Same structure, same prefix size, same alternation pattern

4. OFFSET USAGE:
   - Controls (input/conditioning): CONTROL_OFFSET
   - Generated (output/predicted): TIME_OFFSET only
   - Rests (padding): TIME_OFFSET, DUR=0, REST token

5. THE NUMBER 33:
   - Not arbitrary - balances context vs. sequence length
   - 33 * 6 = 198 tokens for prefix
   - Leaves 1024 - 4 (header) - 198 (prefix) = 822 tokens for body
   - 822 / 6 = 137 alternating pairs possible
   - Last 33 without future controls = symmetric structure
